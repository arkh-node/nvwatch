# nvwatch — сторож NVIDIA-рельса и писательницы

Мониторит наличие «газа» (квоты/доступности) NVIDIA API для моделей GLM,
ведёт статистику отказов (429/5xx/timeout) и мягко будит зависшую
TUI-сессию писательницы (zcode) при обрывах стрима.

## Возможности
- Пробы API каждые N секунд (дефолт 30): 200/429/5xx/timeout
- Спарклайн рельсы в TUI (▁▄█ точки отказа)
- Три уровня будильника: лёгкий пин → пин+задание → /new+полный промпт
- Буфер обрывов (/srv/run/nvwatch_buffer.txt) — заметки для сессии
- RSS писательницы с цветным баром и порогами
- Живой TUI в tmux-окне

## Сборка
```bash
go build -o nvwatch nvwatch.go
```

## Запуск
```bash
# в tmux-окне:
/srv/run/nvwatch/nvwatch -s ohota -probe 30 -ui 5
```

## Зависимости
- NVIDIA_API_KEY в ~/.hermes/.env
- tmux с сессией nevis_zcode, окно писательницы «ohota»

## История

Создан для пары Невис и Алексея, октябрь 2026, после трёх ночей борьбы
с обрывами NVIDIA на длинных генерациях. Урок: стримы рвутся молча,
статус «model streaming» остаётся висеть — сторож ловит это по спиннерам
панели и будит сессию с контекстом из буфера.
